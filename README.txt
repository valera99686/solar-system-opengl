Лабораторна робота №3 з комп'ютерної графіки — модель Сонячної системи
OpenGL 3.3 core, C++17, GLFW 3.4 (власний завантажувач функцій і власна лінійна алгебра)

ЗБИРАННЯ (MSYS2 UCRT64):
    pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-glfw
    mingw32-make            зібрати bin/scene3d.exe і bin/selftest.exe
    mingw32-make check      запустити самоперевірку
    mingw32-make run        запустити програму
Каталог assets має лежати поруч із bin/ (тоді програму можна запускати з будь-якого місця).
Текстури, небо й моделі створює tools/make_assets.py (Python 3, numpy, Pillow); готові файли вже в assets/.

КЕРУВАННЯ:
    W A S D            політ камерою (вільна камера)
    Пробіл / Ctrl      вгору / вниз
    Q / E              крен
    Shift              прискорення
    права кнопка миші  оглядатися (в орбітальному режимі — обертати камеру навколо тіла)
    колесо миші        швидкість польоту (в орбітальному режимі — відстань до тіла)
    Tab / Shift+Tab    вибір тіла (контур за трафаретом)
    1 … 9, 0           політ до тіла: Сонце, Меркурій, Венера, Земля, Марс, Юпітер, Сатурн, Уран, Нептун, корабель
    C                  орбітальна / вільна камера
    R                  загальний вид
    , і .              повільніше / швидше (діб за секунду); P — пауза
    G тіні · F ліхтар (прожектор) · N нормалі (геометричний шейдер) · T текстури · O орбіти
    B пояс астероїдів · L Сонце · X контур · H довідка · I інтерфейс · F12 знімок екрана · Esc вихід

КОМАНДНИЙ РЯДОК:
    scene3d --shot файл.tga --view earth --time 100 --size 1280x720   один кадр без вікна
    scene3d --list-views                                              перелік готових ракурсів
    scene3d --help                                                    усі параметри

СТРУКТУРА:
    src/Math.h          вектори, матриці 4×4, кватерніони
    src/GlFuncs.*       завантаження функцій OpenGL 3.3
    src/Shader.*  Texture.*  Mesh.*  Geometry.*  Assets.*  ресурси на GPU й у пам'яті
    src/Camera.*  SolarSystem.*  Presets.*                     камера й модель сцени
    src/Renderer.*  Hud.*  Offscreen.*                        відтворення кадру
    assets/shaders      GLSL: планети, Сонце, небо, тіні (геометричний шейдер), нормалі, ореол, інтерфейс
    tests/selftest.cpp  самоперевірка
